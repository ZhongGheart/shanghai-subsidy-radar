# open-calls.json

Snapshot of Shanghai funding calls that are still open.

Fields:
- `title_zh` — original Chinese title
- `title_en` — English translation if available (machine translation, check the original)
- `deadline` — ISO date (YYYY-MM-DD)
- `source` — publishing agency
- `url` — official notice URL

Generated from public notices; verify with the official notice before applying.
